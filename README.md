# Simple History Saving Calculator

## Overview
This is a beginner-friendly Python project that performs basic arithmetic calculations and saves calculation history in a text file.

The calculator allows users to:
- Perform arithmetic operations
- Save each calculation automatically
- View previous calculation history
- Clear saved history
- Exit the program safely

---

## Features

✅ Addition (+)  
✅ Subtraction (-)  
✅ Multiplication (*)  
✅ Division (/)  
✅ Modulus (%)  
✅ Saves history in a text file  
✅ View saved calculations  
✅ Clear calculation history  
✅ Error handling for invalid input  
✅ Prevents division by zero
